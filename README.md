# Banking-Analytics-Dashboard---Power-BI
interactive banking analytics and customer intelligence dashboard built with Microsoft Power BI.

An interactive Power BI dashboard designed to analyze banking customers, accounts, transactions, loans, and card portfolios through business-focused KPIs and visualizations.

## Project Overview

This project focuses on transforming banking data into an interactive business intelligence solution that enables users to monitor key metrics and explore performance across different business areas.

The report contains six analytical pages:

* **Executive Summary**
* **Customer Profile**
* **Accounts**
* **Transaction Analysis**
* **Loans**
* **Cards Analysis**

## Objectives

The dashboard is designed to provide insights into:

* Customer and account activity
* Transaction performance and trends
* Loan portfolio and outstanding balances
* Card portfolio and usage
* Branch-level performance
* Customer and product segmentation

## Dashboard Pages

### Executive Summary

Provides a consolidated overview of major banking KPIs and business performance.

### Customer Profile

Analyzes customer characteristics, segments, and related metrics.

### Accounts

Provides insights into account types, account activity, balances, and branch-level performance.

### Transaction Analysis

Analyzes transaction volume, transaction amounts, transaction types, and trends.

### Loans

Analyzes the loan portfolio, loan types, outstanding balances, loan status, and branch-level loan performance.

### Cards Analysis

Provides insights into card types, card networks, active cards, credit limits, and card portfolio performance.
